# Welcome to Octopus Linux!

Octopus Linux is a highly experimental Linux distribution intended to be more resistant to mass surveilance, malware, and spyware while also being highly customizable and useable.

## Key Features
+ Immutable and atomic Fedora Bootc base - this is the head of the octopus!
+ Inaccessible root
+ Rootless distroboxes to run all user-installed software - these are the arms of the octopus!
+ Ansible management of distroboxes
+ Hardened and encrypted /data partition with noexec

## Other Features
+ Hyprland with Rofi and Waybar
+ Chezmoi integration
+ Nvidia and common wifi drivers included
